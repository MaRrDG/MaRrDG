Five years of shipping production software. React, Next.js and Svelte in front; Node.js, Python and PostgreSQL behind; Docker and nginx on my own server. Currently a full-stack developer at [IVFuture](https://www.ivfuture.ro/).

## Selected work

| Project | What it is | Built with |
| --- | --- | --- |
| [**ONRC Expert**](https://onrc-expert.mario-theodor.ro/) | Prepares Romanian trade-register filings as a ready-to-sign pack of official PDFs. Client data lives in an encrypted vault, a condition engine works out what each procedure needs, and published templates are immutable, so a dossier regenerates years later exactly as filed. | Next.js · PostgreSQL · LLM |
| [**FC Solver**](https://sbc-builder.mario-theodor.ro/) | Finds the cheapest squad from your own club for any EA FC Squad Building Challenge, using an exact CP-SAT integer model, and explains why a challenge cannot be done. | Node.js · React · Python |
| [**Cibo**](https://cibo.ro) | Operations platform for restaurants: orders, floor and kitchen kept in sync over WebSockets, plus an Electron client for in-restaurant terminals. | Next.js · Express · MedusaJS |
| [**eDistanta**](https://github.com/MaRrDG/eDistanta) | Route planner for Romania that costs a trip with live fuel prices before it is driven. | React · Express · Turborepo |

## Also built

- [**Plex Couch**](https://github.com/MaRrDG/plex-couch): a phone remote for the PC running Plex. It is a zero-dependency Python server installed as a PWA over a local CA restricted by name constraints to private addresses.
- **Server Hub & `sm` CLI**: my self-hosted ops plane. One command publishes an app, handling Cloudflare DNS, the nginx vhost, Authentik SSO, the hub card and an Uptime Kuma monitor, and rolls back if a step fails. *(private)*
- [**Twist Roleplay**](https://www.twist1.ro/): the core platform for a RAGE:MP multiplayer server, with a modular game engine, a React CEF interface and an async RPC layer.
- [**express-boilerplate**](https://github.com/MaRrDG/express-boilerplate) · [**react-boilerplate**](https://github.com/MaRrDG/react-boilerplate): my starting points for new APIs and apps.
